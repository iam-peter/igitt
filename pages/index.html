igitt

A git tool combining what gitk and git gui do, which also folds changes into any earlier commit and edits the history without touching the working tree.

Download Nightly Source on GitHub

What it does

  • Browse the history of every branch as a graph and search it.
  • Step through every revision of a file in the time-lapse view, each line blamed.
  • Stage and commit single lines, hunks or files.
  • Drag changes onto any earlier commit to fold them in, with a suggestion where they belong.
  • Reword, move, squash and drop commits like git rebase -i, without touching the working tree.
  • Resolve conflicts with ours and theirs side by side, picking each conflict's lines.
  • Push for review to Gerrit and see the state of GitHub pull requests and GitLab merge requests.

Debian and Ubuntu

The APT repository brings igitt with its own Qt and installs git with it. It needs git 2.40, so Ubuntu 24.04 or Debian 13 and newer.

sudo curl -fsSLo /usr/share/keyrings/igitt-archive-keyring.asc https://iam-peter.github.io/igitt/key.asc
echo "deb [signed-by=/usr/share/keyrings/igitt-archive-keyring.asc] https://iam-peter.github.io/igitt/apt stable main" | sudo tee /etc/apt/sources.list.d/igitt.list
sudo apt update && sudo apt install igitt

The repository is signed with the key E61A 05C6 0E8A D423 C403 6586 D3D1 B02A 57B5 9B54.

Other systems

Each release has an AppImage for any Linux, a zip for Windows and a disk image for macOS. igitt runs the git command line, so git 2.40 or newer has to be installed. The macOS app isn't signed: open it with a right click and Open the first time.
